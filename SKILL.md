# ExoPython (`exopython`) — Complete Unrestricted Technical Manual & AI Skill Reference

`exopython` (`import exopython as exo`, or internal package `exopy`) provides complete programmatic read, write, AST, binary, replay, audio, merge, obfuscation, and decompilation control over Exoracer (`.exolvl`) files.

---

## 1. Execution Model, Internal State & Core Rules

### Active Level Singleton (`exopy._state`)
- `exopy._state.active_level`: Holds the currently active `ExoLevel` instance.
- `exopy._state.generator_mode`: Global `bool` (default `False`). Toggled via `exo.set_generator_mode(True)` or per-call `generator_mode=True` on `lvl.export(...)` / `exo.decompile(...)`. When `True`, `export()` and `decompile()` return structured metadata dicts instead of a file path or code string.
- `exopy._state.get_level()`: Returns `active_level` or raises `RuntimeError("Call exo.init(...) first")`.
- Every `CreateObj`, `CreateLayer`, `CreateImage`, `CreatePrefab`, `CreateBrush`, `exovar.*` constructor, `exoscript.create`/`function`/`@func`, `audio_to_script`, and `merge_level` mutates `exo._state.active_level` directly.
- You can swap between multiple in-memory levels at any time by assigning `exo._state.active_level = other_level`.

### ID Allocators on `ExoLevel`
Each `ExoLevel` maintains independent monotonically increasing counters:
- `lvl._eid` (starts at `1`): `lvl._next_entity_id()` — assigned to `GameObject.entity_id`.
- `lvl._lid` (starts at `2`, because `Layer(1, "Layer 1")` is created automatically): `lvl._next_layer_id()`.
- `lvl._vid` (starts at `1`): `lvl._next_var_id()` — shared across both `lvl.global_variables` and script-local `sc.variables`.
- `lvl._sid` (starts at `1`): `lvl._next_script_id()` — assigned to `Script.script_id`.
- `lvl._pid` (starts at `1`): `lvl._next_param_id()` — assigned to `Parameter.parameter_id`.
- `lvl._pat_id` (starts at `1`): `lvl._next_pattern_id()` — assigned to `Pattern.pattern_id`.
- `lvl._prefab_id` (starts at `1`): `lvl._next_prefab_id()` — assigned to `Prefab.prefab_id`.
- `lvl._brush_id` (starts at `1`): `lvl._next_brush_id()` — assigned to `Brush.brush_id`.
- `lvl._return_regs`: `dict[int, Variable]` caching auto-allocated global return variables (`_rv_bool`, `_rv_int`, `_rv_float`, etc.) keyed by `StaticType`.
- `lvl._stdlib_cache`: `dict[str, Script]` caching `@exoscript.func` helpers generated by `exopython.stdlib`.

### Essential Lifecycle Rules
1. **Always call `exo.init(...)` first** (or assign `exo._state.active_level`).
2. **Always call `.pack()`** on `GameObject` and `Script` instances (`@exoscript.func` calls `.pack()` automatically). Unpacked objects/scripts never enter `lvl.objects` / `layer.children` / `lvl.nova_scripts`.
3. **`start` and `finish` objects are completely optional.** Exoracer loads and runs levels without either object.
4. **Build-time Python vs. Runtime `NovaValue` AST:**
   - Values passed to `exo.init(...)`, `exo.CreateObj(...)`, and `.settings({...})` evaluate at Python build time.
   - Expressions inside `exoscript` actions, conditions, and `exovar.*` operators build `NovaValue` AST trees serialized into the `.exolvl` binary and evaluated by Exoracer's runtime VM. Never use Python `if`/`while` on `NovaValue`/`Variable`/`Parameter` objects—use `.if_else(...)` and `.repeat_while(...)`.
5. **Blocking (`wait=True`) vs. Non-blocking (`wait=False`):**
   - `wait=True` suspends the current script fiber until the action, tween duration, loop block, or function call completes.
   - `wait=False` dispatches the action immediately and proceeds to the next action on the same frame.

### Operator Overloading on `NovaValue`, `Variable`, and `Parameter`
- `a + b`: Automatically emits `StringConcat` (`98`) if either operand is string-typed, `VectorAdd` (`106`) if either is vector-typed, `FloatAdd` (`58`) if either is float-typed, or `IntAdd` (`40`) otherwise.
- `a - b`: Emits `VectorSubtract` (`107`), `FloatSubtract` (`59`), or `IntSubtract` (`41`).
- `a * b`: Emits `VectorMultiply` (`108`, coercing `b` to float), `FloatMultiply` (`60`), or `IntMultiply` (`42`).
- `a / b`: Emits `VectorDivide` (`109`, coercing `b` to float), `FloatDivide` (`61`), or `IntDivide` (`43`).
- `a % b`: Emits `FloatModulo` (`62`) or `IntModulo` (`44`).
- `a < b` (`17`), `a <= b` (`18`), `a > b` (`19`), `a >= b` (`20`), `a.eq(b)` (`6`), `a.ne(b)` (`12`).
- **Gotcha:** For equality on non-numeric types, use `exovar.eq_bool`, `eq_str`, `eq_color`, `eq_vec`, `eq_obj` (and `ne_*` variants) instead of `.eq()`/`.ne()` which emit `BoolEqualNumber`/`BoolNotEqualNumber`.

## 5. NovaScripts, Functions, Return Registers & Complete `ActionID` Table (`exopy/scripts.py`)

### Creating Scripts & Functions
```python
from exopython import scripts as exoscript, variables as exovar

# Event-driven script
sc = exoscript.create("Controller", activation_count=0, condition=True)
sc.on(0)  # Add one or more Activator(activator_type, *params) triggers
local_counter = sc.local("i", exovar.Int, 0)  # Script-scoped local variable
sc.wait(0.5).set_var(local_counter, local_counter + 1).pack()

# Reusable typed function (@exoscript.func auto-packs and infers StaticType from annotations/defaults)
@exoscript.func
def move_and_tint(
    targets: exovar.ObjectSet,
    dest: exovar.Vector,
    tint: exovar.Color = "#00F5FF",
    dur: exovar.Float = 0.5,
):
    return (
        exoscript.block()
        .move(targets, dest, duration=dur, wait=False)
        .set_color(targets, tint, duration=dur, wait=True)
        .ret(True, exovar.Bool)  # Writes to shared global return register _rv_bool
    )

# Calling a function & reading its return register
ret_flag = exovar.return_reg(exovar.StaticType.Bool)
sc.call(move_and_tint, [obj], (10.0, 4.0), tint="#FF4D6D", dur=0.8, wait=True)
sc.if_else(ret_flag, exoscript.block().play_sound("blip"))
```

### Audio Sequencer (`exopy/sounds.py`)
```python
# Analyze audio into [(wait_sec, [(semitones, volume), ...]), ...]
events = exo.analyze_audio(
    "track.wav",              # .wav native; .mp3/.ogg/etc. via ffmpeg if installed
```

### Export, Metadata Footer & Owner-Key Obfuscation (`exopy/__init__.py` & `exopy/decompile.py`)
```python
lvl.export(
    "out.exolvl",
    compress=True,          # gzip-compress output (standard Exoracer format)
    generator_mode=None,    # Override global generator_mode
    obfuscate=True,         # MD5-mangles variable/script/param names + stores owner key
    metadata_mode="footer", # "footer" (EXPY...YPXE trailer) | "object" (__EXOPY_META__ text obj) | "none"
    include_meta=False,
)
```
- **Owner Key System (`~/.exopy_keys.txt`):** When `obfuscate=True`, a 128-bit hex key is persisted in `~/.exopy_keys.txt` (chmod `0o600`) mapped to `lvl.uuid`, and its 8-byte SHA-256 prefix is embedded in the `EXPY` footer. Calling `exo.decompile(...)` on the owner's machine unlocks readable Python; calling `exo.decompile(...)` without the matching owner key packs the output into an XOR + zlib + base85 `marshal` bytecode stub (`_pack_obfuscated_py`).

## 8. Exact Binary Wire Layout (`NYA^` v23)

For binary-level debugging or custom serializers (`exopy/binary.py`):
1. `b"NYA^"` (`4` bytes)
2. `LocalLevel`: `serialization_version: i32` (`23`), `uuid: varint-str`, `level_version: i32`, `name: varint-str`, `thumbnail: varint-str`, `creation_ticks: i64` (C# `DateTime.ToBinary()` UTC ticks), `update_ticks: i64`, `author_ms: i64`, `author_laps: Vec<i64>`, `silver_ms: i64`, `gold_ms: i64`, `laps: i32`, `private: bool`, `nova_level: bool`.
3. `LevelData`:
   - `uuid: varint-str`, `level_version: i32`, `nova_level: bool`
   - `LegacyTileLayers`: `6` × `Vec<i32>`
   - `objects: Vec<Object>`, `layers: Vec<Layer>`, `prefabs: Vec<Prefab>`, `brushes: Vec<Brush>`, `patterns: Vec<Pattern>`
   - If `ver >= 17`: `color_palette: Vec<ColorRGBA_f32>`
   - `author_ms: i64`, `author_laps: Vec<i64>`, `silver_ms: i64`, `gold_ms: i64`, `laps: i32`, `center_camera: bool`, `legacy_scripts: Vec<i32>`
   - If `ver >= 19`: `unknown2: [u8; 4]`
   - `nova_scripts: Vec<NovaScript>` (where each `Variable` has `unknown4: [u8; 4]` after `static_type` when `ver >= 23`, and each `NovaValue` has `unknown5: [u8; 1]` before `int_list_value` and `unknown6: [u8; 4]` between `int_list_value` and `sub_values` when `ver >= 19`)
   - If `ver >= 23`: `unknown3: [u8; 4]`
   - `global_variables: Vec<Variable>`
   - `theme: varint-str`, `custom_bg_color: ColorRGBA_f32`, `TerrainCopyStyle` (`unknown1: [u8; 4]` + 12 fields)
   - `default_music: bool`, `music_ids: Vec<varint-str>`, `allow_direction_change: bool`, `disable_replays: bool`, `disable_revive_pads: bool`, `disable_start_anim: bool`
   - If `ver >= 23`: `enable_sensors: bool`, `disable_screen_rotation: bool`
   - `gravity: Vec2_f32`
4. `AuthorReplay`: `Vec<u8>` (prefixed by `i32` byte length)
5. Optional `EXPY` footer: `b"EXPY" + flags: u8 + wm_len: u8 + wm_bytes + key_hash[0..8] + body_len: u16le + b"YPXE"`, all wrapped in gzip.
